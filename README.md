# User Profile Card

A simple User Profile Card created using HTML and CSS.

## About the Project

This project displays my profile picture, name, and student details. It also includes links that allow users to connect with me easily.

## Features

- Displays my profile picture
- Shows my name
- Shows that I am a student at VemanaIT and currently in 3rd Year
- LinkedIn icon that redirects to my LinkedIn profile
- GitHub icon that redirects to my GitHub profile
- Mail icon that allows users to send me an email
- Contact button that allows users to contact me through my phone number

## Technologies Used

- HTML
- CSS
- Bootstrap Icons
